\# Estándares de Seguridad Informática - Puls-ar IT



En Puls-ar, la seguridad no es una capa final, sino un pilar fundamental del ciclo de vida de desarrollo (SDLC). Bajo la dirección de especialistas con postgrado en Seguridad Informática, aplicamos los siguientes principios:



\### 1. Principio de Mínimo Privilegio (PoLP)

\- Acceso restringido a bases de datos y entornos de producción.

\- Gestión de secretos y variables de entorno mediante bóvedas cifradas (Vaults).



\### 2. Sanitización y Validación de Datos

\- Protección nativa contra inyecciones SQL en arquitecturas PostgreSQL y SQL Server.

\- Validación estricta de esquemas XML/JSON en todos nuestros WebServices.



\### 3. Cifrado de Datos en Reposo y Tránsito

\- Implementación obligatoria de SSL/TLS para toda comunicación.

\- Algoritmos de hashing de alta seguridad (Bcrypt/Argon2) para la gestión de identidades.



\### 4. Auditoría y Trazabilidad

\- Logs de actividad detallados para la detección temprana de anomalías.

\- Cumplimiento de estándares de integridad de datos.
